# 隔日极限做空策略文档

## 策略概述

| 项目 | 说明 |
|------|------|
| 策略名称 | overnight_limit_short |
| 策略类型 | 隔夜限价做空 |
| 适用品种 | 股指期货（IF） |
| 交易方向 | 仅做空 |
| 代码文件 | strategies.py → OvernightLimitShortStrategy |

## 策略逻辑

1. **开空条件**：当日最高价 >= 前一日收盘价 × (1 + entry_pct)
2. **平空条件**：
   - 盈利5%：价格 <= 开仓价 × (1 - 5%)
   - 亏损2%：价格 >= 开仓价 × (1 + 2%)
3. **限价成交**：未触发则不成交，触发后以触发价成交
4. **每日更新**：无论是否成交，收盘后更新前一日收盘价

## 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| position_size | 1 | 每次开仓手数 |
| entry_pct | 0.01 | 开空偏移百分比（+1%） |
| take_profit | 0.05 | 止盈百分比（5%） |
| stop_loss | 0.02 | 止损百分比（2%） |

## 伪代码

```
prev_close = 无
entry_price = 无

每根bar:
  if prev_close 为空:
    prev_close = bar['close']
    继续下一根

  # 持仓中：检查止盈止损
  if 有空仓 且 entry_price 有值:
    # 盈利5%平仓
    if bar['low'] <= entry_price * (1 - 5%):
      以 entry_price * (1 - 5%) 价格买入平空
      entry_price = 无
      prev_close = bar['close']
      继续下一根
    
    # 亏损2%平仓
    if bar['high'] >= entry_price * (1 + 2%):
      以 entry_price * (1 + 2%) 价格买入平空
      entry_price = 无
      prev_close = bar['close']
      继续下一根

  # 空仓：检查开空条件
  if 无仓 且 bar['high'] >= prev_close * (1 + entry_pct):
    以 prev_close * (1 + entry_pct) 价格卖出开空
    entry_price = prev_close * (1 + entry_pct)
    prev_close = bar['close']
    继续下一根

  # 无交易时更新收盘价
  prev_close = bar['close']
```
