# 股指期货回测系统

一个功能完整的股指期货回测框架，支持多种量化策略、绩效分析和图形化界面操作。

## 功能特点

- **图形化界面**: 直观的GUI界面，所有配置和结果可视化展示
- **多种数据源支持**: AKShare（免费）、Tushare、本地CSV
- **丰富的策略库**: 5种经典量化策略，支持自定义扩展
- **完整的回测引擎**: 支持保证金、手续费、滑点模拟
- **详细的绩效分析**: 12项专业指标（夏普比率、最大回撤、胜率等）
- **可视化报表**: 权益曲线、月度收益、回撤分析、交易分析
- **实时响应**: 窗口大小变化时图表自动缩放

## 快速开始

### 方式一：图形界面运行（推荐）

```bash
python gui.py
```

启动后在界面中：
1. 配置数据源、合约代码、日期范围
2. 设置初始资金、保证金、手续费
3. 选择策略并调整参数
4. 点击"开始回测"
5. 在右侧标签页查看结果

### 方式二：命令行运行

```bash
# 使用默认配置运行
python main.py

# 指定合约和日期
python main.py --symbol IF0 --start 2025-09-01 --end 2026-09-01

# 指定策略
python main.py --strategy bollinger

# 列出可用策略
python main.py --list-strategies
```

### 方式三：Python代码调用

```python
from config import BacktestConfig
from main import run_backtest

# 创建配置
config = BacktestConfig(
    symbol="IF0",
    start_date="2025-09-01",
    end_date="2026-09-01",
    strategy_name="bollinger",
    strategy_params={'window': 20, 'num_std': 2.0}
)

# 运行回测
result = run_backtest(config)
```

## 交易分析图表解读

交易分析标签页包含4个子图表，用于分析交易行为和特征：

### 1. 开仓方向分布图

**位置**: 左上角

**含义**: 统计开多和开空操作的次数分布

**如何看**:
- 绿色柱体代表开多次数，红色柱体代表开空次数
- 理想情况下开多开空次数应大致平衡
- 如果单边过多，说明策略偏向做多或做空

**分析要点**:
| 情况 | 说明 |
|-----|------|
| 开多开空均衡 | 策略双向交易，适应性好 |
| 开多偏多 | 策略偏向做多，适合上涨行情 |
| 开空偏多 | 策略偏向做空，适合下跌行情 |

### 2. 交易日期分布图

**位置**: 右上角

**含义**: 统计每个交易日发生的交易次数

**如何看**:
- X轴为交易日序号（按时间顺序）
- Y轴为当日交易次数
- 柱体越高表示该日交易越频繁

**分析要点**:
| 情况 | 说明 |
|-----|------|
| 分布均匀 | 策略稳定触发信号 |
| 某些日子集中 | 可能是行情剧烈波动期 |
| 长期无交易 | 策略在震荡期可能失效 |

### 3. 开仓价格分布图

**位置**: 左下角

**含义**: 统计开多和开空的成交价格分布

**如何看**:
- 绿色柱体为开多成交价格分布
- 红色柱体为开空成交价格分布
- X轴为成交价格，Y轴为该价格区间成交次数

**分析要点**:
| 情况 | 说明 |
|-----|------|
| 开多价格 < 平仓价格 | 多头盈利，策略有效 |
| 开多价格 > 平仓价格 | 多头亏损，需要优化 |
| 开空价格 > 平仓价格 | 空头盈利，策略有效 |
| 开空价格 < 平仓价格 | 空头亏损，需要优化 |
| 价格分布集中 | 策略在特定价格区间交易 |
| 价格分布分散 | 策略适应不同价格环境 |

### 4. 累计交易数量图

**位置**: 右下角

**含义**: 显示随时间推移的累计交易手数

**如何看**:
- X轴为交易序号（按时间顺序）
- Y轴为累计交易手数
- 斜率越陡表示交易越频繁

**分析要点**:
| 情况 | 说明 |
|-----|------|
| 直线上升 | 交易频率稳定 |
| 斜率变化 | 交易频率有变化 |
| 水平线段 | 某段时间无交易 |

### 综合分析建议

1. **交易频率**: 通过累计交易数量图判断，过频可能增加成本，过低可能错过机会
2. **盈亏来源**: 通过开仓价格分布图分析，盈利主要来自哪些价格区间
3. **稳定性**: 通过日期分布图判断，策略是否稳定触发信号
4. **均衡性**: 通过开仓方向分布图判断，策略开多开空是否平衡

## 绩效指标说明

| 指标 | 说明 | 参考值 |
|-----|------|-------|
| 总收益率 | 策略总收益百分比 | >10%为佳 |
| 年化收益率 | 换算成年化收益 | >15%为佳 |
| 年化波动率 | 收益波动程度 | <20%为佳 |
| 最大回撤 | 最大亏损幅度 | <15%为佳 |
| 夏普比率 | 风险调整后收益 | >1.5为佳 |
| 索提诺比率 | 下行风险调整收益 | >2.0为佳 |
| 卡玛比率 | 年化收益/最大回撤 | >2.0为佳 |
| 胜率 | 盈利交易占比 | >50%为佳 |
| 盈亏比 | 平均盈利/平均亏损 | >1.5为佳 |

## 期货交易术语

本系统采用期货交易标准术语：

| 术语 | 含义 | 对应操作 |
|-----|------|---------|
| 开多 | 买入开仓，预期价格上涨 | Buy to Open |
| 开空 | 卖出开仓，预期价格下跌 | Sell to Open |
| 平多 | 卖出平仓，了结多头头寸 | Sell to Close |
| 平空 | 买入平仓，了结空头头寸 | Buy to Close |
| 多头 | 持有多仓的头寸 | Long Position |
| 空头 | 持有空仓的头寸 | Short Position |

## 自定义策略

继承 `Strategy` 类并实现 `on_bar` 方法即可创建自定义策略：

```python
from engine import Strategy, BacktestEngine, OrderSide, OrderType

class MyStrategy(Strategy):
    def __init__(self, params=None):
        super().__init__(params or {})
        self.prices = []
    
    def on_bar(self, engine: BacktestEngine, bar: dict):
        """
        每根K线触发
        
        Args:
            engine: 回测引擎，用于下单
            bar: 当前K线数据 {date, open, high, low, close, volume}
        """
        self.prices.append(bar['close'])
        
        # 实现你的交易逻辑
        if len(self.prices) > 20:
            ma = sum(self.prices[-20:]) / 20
            
            # 获取当前持仓
            current_pos = 0
            for pos in engine.portfolio.positions.values():
                current_pos = pos.quantity if pos.side.value == 'long' else -pos.quantity
            
            # 金叉做多
            if bar['close'] > ma and current_pos <= 0:
                if current_pos < 0:
                    engine.submit_order('IF', OrderSide.BUY, abs(current_pos))
                engine.submit_order('IF', OrderSide.BUY, 1)
            
            # 死叉做空
            elif bar['close'] < ma and current_pos >= 0:
                if current_pos > 0:
                    engine.submit_order('IF', OrderSide.SELL, abs(current_pos))
                engine.submit_order('IF', OrderSide.SELL, 1)
```

## 常见问题

**Q: 为什么获取不到数据？**
A: 检查网络连接，确保合约代码正确，尝试使用主力合约 `IF0`

**Q: 如何调整策略参数？**
A: 在GUI界面的"策略参数"区域直接修改，或在代码中传入参数字典

**Q: 如何导出交易记录？**
A: 在GUI界面的"交易记录"标签页点击"导出CSV"按钮
